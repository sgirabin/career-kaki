# CareerKaki Web

This folder contains the Next.js frontend for CareerKaki.

## Setup

1. `cd apps/web`
2. `npm install`
3. `npm run dev`

## Available scripts

- `npm run dev` - start the development server
- `npm run build` - build the production bundle
- `npm run start` - run the production server
- `npm run lint` - run Next.js lint checks

## Notes

- The app uses Next.js App Router with TypeScript.
- Connect the frontend to the AWS worker backend via API routes or environment variables.
- Use the Vercel AI SDK in future workflows to orchestrate career automation.
